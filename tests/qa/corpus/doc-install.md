Installazione
=============

Il programma non richiede una compilazione separata del frontend.

Prerequisiti
------------

    sudo apt install libwebkit2gtk-4.1-dev build-essential
    cargo install tauri-cli --version "^2"

Il blocco qui sopra e' indentato di quattro spazi: e' codice, non prosa.

Vedi anche la [guida ufficiale][guida] e le [note di rilascio][note].

Se qualcosa non parte, quasi sempre e' il pacchetto di sviluppo che
manca[^1].

[guida]: https://example.invalid/start/
[note]: https://example.invalid/releases/ "Note di rilascio"

[^1]: Su alcune distribuzioni si chiama in un altro modo. Cercare il
    nome esatto con il gestore di pacchetti.
